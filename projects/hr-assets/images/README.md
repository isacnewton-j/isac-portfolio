# HR Assets Images (local)

Drop your exported screenshots into this folder on your local machine. The HR case study page (`projects/hr-dashboard.html`) will automatically prefer files in this folder when previewing locally.

Recommended filenames (your screenshots are recognized automatically):
- `hr-hero.png` or `hr-hero-page1-Overview.png` — main hero screenshot (1200×675)
- `hr-1.png` or `hr-page2-Workforce Dempgrahpics.png` — workforce demographics page
- `hr-2.png` or `hr-page3-Retention Productivity.png` — retention & productivity page

Note: filenames with spaces or mixed case are accepted; the page checks common variants in both `hr-assets/` and this `hr-assets/images/` folder.

Do NOT commit sensitive PBIX files or raw data to a public repository. Keep PBIX files private and only use screenshots for the public portfolio.
